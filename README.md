# Tixelx Studio

A small, responsive static website for Tixelx Studio. It includes a product-led homepage, Zikr and Analytics Portal showcases, and a standalone privacy policy.

## Preview locally

Run `node server.mjs`, then open <http://localhost:4174>.

## Publish on GitHub Pages

Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select your branch, and use the root (`/`) folder.

No build step or dependencies are required.
